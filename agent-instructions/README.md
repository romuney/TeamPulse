# Инструкции для агентов — борды Proteus и HTML-отчёты команды

Короткий командный набор правил для ИИ-агентов (Claude Code и др.), которые делают борды Proteus
(форк Superset 2.1.0, ClickHouse 24.8, кастомные JS-чарты в iframe) и автономные HTML-отчёты.
Собран из рабочих проектов TeamPulse Hub, Proteus Adoption, HRBP HUB и «Детальные списки»
и сверен с их кодом на 14.10.2026.

Это **выжимка**. Полные правила с кодами (SP-06, CH-14, CJ-21…), доказательствами и kit — в большом
гайде `../proteus-playbook/` (вход — `SKILL.md`). Здесь — то, что агент должен знать всегда.

## Как подключить к проекту

1. Скопируй папку `agent-instructions/` в репозиторий проекта (или держи ссылку на эту — romuney/TeamPulse, main).
2. В `CLAUDE.md` / `AGENTS.md` проекта добавь блок (готовый шаблон — в конце `07-delivery-process.md`):

   ```markdown
   ## Инструкции команды
   Перед работой прочитай agent-instructions/README.md и файлы под задачу:
   вид — 01, SQL — 02, JS чарта — 03, CSS борда — 04, поведение — 05; перед сдачей — 06 и 07.
   Полный гайд с кодами правил — proteus-playbook/SKILL.md.
   Решения владельца проекта важнее этих инструкций — записывай их в CLAUDE.md проекта.
   ```
3. Решения конкретного проекта (свой акцентный цвет, раскладка, состав метрик) пиши в CLAUDE.md
   проекта, а не сюда. Сюда — только то, что верно для всех проектов.

## Три правила, которые не обсуждаются

1. **Шрифт — только Arial** (`Arial, Helvetica, sans-serif`), веса 400 и 700, «полужирный» для названий строк —
   `#111318` + `-webkit-text-stroke:.25px currentColor`. Кегли — только из шкалы ДС, мельче не делать.
2. **Агенту бой недоступен**: всё, что уходит владельцу, проходит стенд и kit; правка для владельца —
   «замени из файла N целиком», с проверками и стоп-точками.
3. **Боевые данные в репозиторий не кладём**: ни логинов, ни ФИО, ни тел ответов и HAR — только агрегаты и выводы.

## Как обновлять

- Правило живёт в одном месте: тема → её файл. Нашли новое — правьте файл темы и, если правило
  универсальное, добавьте строку в `06-antipatterns.md`.
- При расхождении с `proteus-playbook/` верна более свежая проверенная практика: поправьте оба места.
- Без истории итераций: пишем итоговое правило и одну дату решения.
