## Топ-15 самых дорогих ошибок

Каждая уже стоила поставки, утечки или дня переписки с владельцем.

1. ❌ Логин в `{% set me = current_username() %}` → ✅ вызов в `{{ … }}` одной строкой → чужой ответ из кэша на 12 ч,
   три отчёта (07.10) → AC-07, AC-08.
2. ❌ Непроверяемое (загрузчик кода из ответа, `new Function`) сразу в основной поставке → ✅ пробой на одном чарте копии
   борда с откатом → сломались все четыре чарта (07.10) → CJ-22, DV-08.
3. ❌ Прокручиваемый документ iframe, голый `window.onerror` → ✅ `overflow:hidden` и обёртка `onerror` в начале `mount()`
   → на Windows чарты появлялись и пропадали (06.10) → SB-03.
4. ❌ Длинный SQL (34 КБ, выражения по колонкам) при логине в ключе → ✅ плоский массив, `reindent` ≤ 1 с → «Применить»
   20 с при 2 с ClickHouse (08.10) → SP-15, SP-22.
5. ❌ Области кросс-фильтров мышкой → ✅ только JSON-метаданными → фильтр не применялся в трёх проектах → MC-09.
6. ❌ `\'` в литерале → ✅ `''`, слэш — раньше кавычки → «multiple statements» или молча другой ответ → SP-06.
7. ❌ `[…]` со «]» внутри → ✅ `array(…)` → Code 36 на открытии → SP-07.
8. ❌ Логин в ключе у ответа, общего для всех → ✅ отдельный датасет без вызова логина → холодное открытие у каждого
   коллеги → AC-06, DS-10.
9. ❌ Несжатый JS → ✅ terser 5.51.2 (`kit/min.cjs`) → 169 КБ уходили 5,8 с на каждый `chart/data` → CJ-21.
10. ❌ Стенд не на ClickHouse 24.8, замер старым анализатором → ✅ chdb 2.1.1, новый анализатор → Code 386 в бою при
    зелёном стенде → CH-01, ST-01.
11. ❌ Общая CTE в нескольких местах → ✅ линейная цепочка, контекст одним скаляром → 11,7 с вместо 2,1 с → CH-05, CH-06.
12. ❌ Лимит строк чарта по умолчанию → ✅ 50 000 явно, `meta.rows` против `data.length` → молча срезано до 10 000 →
    DS-24, DS-25.
13. ❌ Правка «сломалось» вслепую → ✅ сначала текст на месте чарта, консоль, Network → причина поломки так и не найдена →
    PR-10.
14. ❌ Высота ряда и поля по фото → ✅ сниппет разметки до поставки → четыре поставки CSS за вечер (08.10) → BC-22, DV-35.
15. ❌ Данные боя в репозитории → ✅ только агрегаты и выводы → удаляли вместе с историей (07.10) → AC-16, PR-06.
