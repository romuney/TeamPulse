# 05. UX-паттерны: тур, подсказки, «Что видно», срез, год к году

Фишки бордов Proteus и HTML-отчётов (TeamPulse, Adoption, HRBP HUB, «Детальные списки» — DL) глазами пользователя.
Токены — [01](01-design-system.md), техника JS — [03](03-chart-js.md), CSS борда и затемнение страницы —
[04](04-board-css.md), стоп-лист — [06](06-antipatterns.md), стенд — [07](07-delivery-process.md).

## 0. Главное

1. **Число честное или его нет** (§1). Тексты — **на «ты»** (§2).
2. **Тур «Как работать» — только по кнопке**, на весь экран, без памяти «уже показан» (§3).
3. **Подсказка — один механизм**, только с новой информацией (§4). **Инсайт — по порогам, без ИИ** (§5).
4. **Клик выбирает, а не уводит; выбор подписан там, где меняет цифры**; вёрстка не двигается (§7).
5. **Пустое — пусто, ошибка — текстом с действием** (§12).

## 1. Смысловые правила (ломать нельзя)

- **База — из фильтров, а не из подразделения**: HQ → всё HQ, HQ + IT → всё HQ IT. Подпись базы — автоматически и на
  виду. Переход в юнит базу не меняет — скажи это в подсказке кнопки.
- **Есть KPI — сравнение только с ним, базы рядом нет**, одинаково везде: карточка, ячейка, спарклайн, график. Нет KPI —
  назад к базе.
- **С базой сравнивай только относительные метрики.** Счётные — масштаб, а не оценка: «не сравнивается», без линии базы.
- **Изменение называет период**: «+3 к маю». Месяц — из данных. Направление — знаком (`+7`, `−4`), оценка — цветом;
  стрелок нет. У «больше не значит лучше» цвета нет.
- **Светофор — зелёный и красный**, остальное серое, мёртвая зона ±5 %, жёлтого нет.
- **Доля без знаменателя — `null`, не ноль**: разрыв линии, прочерк, без оценки и инсайта.
- **Малые выборки не оценивай** (< 30 человек — прочерк без цвета, в конец сортировки); рядом с долей — люди: «16 из 17
  новичков» (UI-24).
- **Не выдумывай молча**: метрика без источника — «демо», без светофора и выводов (UI-26); допущение — сноской.
- **Цифры текста = цифры графика**: выводы и «Будет N» — из тех же рядов и той же семантикой, что SQL.
- Даты — от свежести данных, а не от часов браузера (UI-27).

## 2. Тексты интерфейса

- **На «ты»** везде, включая ошибки: «сними выбор», «наведи», «твой логин» (владелец, 09.10).
- Подпись говорит, **что произойдёт** («подробнее» / «свернуть»). Названия кнопок — как на экране.
- Проговаривай: с чем сравнивается число, что фильтр меняет и что нет, где данные придуманы, почему нет цвета. Не
  пиши «Ошибка / Внимание» без действия, нераскрытых аббревиатур, «Ничего не выбрано».
- **Подсказка:** заголовок — что это; фраза — смысл; числа — строками; оговорки — сноской; не повторяй видимое в строке.
- **Пустое состояние:** что случилось + что сделать: «Нет данных по выбранным разрезам. Сними один из разрезов в шапке».
- **Термины** — по наведению из одного словаря (TeamPulse `TPSTORY.GL`, определения из `hint` метрики).

> Расхождение: TeamPulse `DESIGN_SYSTEM.md §4.12/§10`, образцы CJ-19 и шаг тура HRBP — на «вы». Актуально «ты».

## 3. Тур «Как работать» (TR)

**Зачем.** В чарт не положить видео и справку, Proteus не помнит вход. Объяснение — живой тур по отчёту: экран затемнён,
подсвечена цель, карточка со стрелкой: «это — вот что, нажми — будет вот что». Эталон — Adoption, три чарта, в бою с 07.10.
**Когда:** в любом отчёте больше чем с одним контролом; новый элемент или вкладка — новый шаг в том же коммите (TR-20).

### 3.1. Запуск и «уже показан»

- **Только кнопка «Как работать»** справа в шапке; последний шаг подсвечивает её: «Тур всегда под рукой» (TR-01, TR-03).
- **Ни показа при первом входе, ни памяти**: ни `localStorage`, ни cookies, ни параметра адреса. В песочнице без
  `allow-same-origin` хранилище бросает исключение (SB-02); приглашение «Впервые?» висело бы при каждом входе.
- Помнится только **ход тура** — `state.tour` в `window.__pvtState`: переживает перезапуск скрипта, не перезагрузку.
- Автономный HTML (TeamPulse-макет) открывает справку при первом входе по `tp_onboarded` в `localStorage` в `try/catch`,
  `?tour=0` — для скриншотов; в пробнике Proteus это выключено. В чарты не переносить.

> Расхождение: `DESIGN_SYSTEM.md §10` TeamPulse — «показывается при первом входе». Для Proteus верно TR-01.

### 3.2. Шаги

- Декларативно в `tourSteps()`, без логики показа. **Цели нет — шаг пропускается в ту же сторону** (`t.dir`) (TR-02).
- **`need` — только по тому, что тур не меняет** (есть ли пользователь, страниц > 1, вид «таблица/сводная»), иначе после
  «Показать» «N из M» врёт (TR-08).
- **Порядок:** вводная «<Отчёт> за минуту» (вся страница затемнена, 4–5 правил чтения, лучше с живыми числами из ответа)
  → шапка → список (разрезы, поиск, выбор строки, колонки, фильтры) → панель (показатели, «Что видно», вкладки) → кнопка тура.
- **Текст:** заголовок 1–3 слова, 1–3 фразы: что это и что будет при клике; кнопки — жирным. Про инсайты: «правилами по
  тем же числам, без ИИ». Объём — 13–16 шагов на лист.
- С вкладками: тур по текущей, в конце — «Дальше — тур по вкладке „…“» (`TOUR_NEXT`), в конце цепочки — «Готово».

```js
add({ sel: P + '-cat tbody tr[role=button]', pad: 2, lock: true, title: 'Выбрать строку',
  html: '<b>Клик</b> — выбрать: панель справа покажет только это. <b>Shift+клик</b> — несколько. Повторный клик снимает.' });
```

Поля шага (общие у HRBP, DL, Adoption): `title`, `html`, `intro`, `sel`, `pad`, `lock`, `demo`+`done`, `need`,
`remote: '<чарт>:<цель>'`, `drawer`, `last`.

### 3.3. Подсветка и карточка

- **Слой в `body` iframe**, один; старый при монтаже удаляется (TR-04).
- **Четыре шторки** `fixed`, `rgba(17,24,39,.55)`, **без скругления**, клики мимо цели не проходят; пятая — крышка на
  цель при `lock`. **Рамка** — `0 0 0 2px` акцент + `0 0 0 6px` акцент `.22`, радиус 10.
- **Карточка** `role="dialog"`, 340 px, радиус 12, стрелка на центр цели; «Как работать · N из M» + ✕; «Назад» и
  «Далее/Готово», фокус на главной. z-index 99990–99993, тултип на время тура спрятан.
- **Место:** снизу → сверху → справа → слева; поля 12 / 14; по вертикали — в **видимой части iframe** (`visV()`), не в
  `innerHeight`; цель за краем — прокрутить к ней; колесо не блокировать (TR-06).
- **Плавность:** всё едет `.2s`; **первый кадр без анимации** (`-tnoa`); шаг без цели — «дырка» схлопывается в точку
  прошлой цели, шторки не уезжают в (0, 0) (TR-14).
- **`tourSync()` после каждой перерисовки и `resize`**: рамка на новой позиции, `done()` выполнен — следующий шаг (TR-05).
- **«Нажми — будет»**: «Показать» ведёт нарисованный курсор к цели и зовёт тот же `onClick`. Запросы и переходы — только
  `lock`, тур не дёргает датасет (TR-07).
- **Esc** закрывает всегда, **← →** листают (кроме фокуса в поле ввода); слушатель на `document` с `capture` (TR-10).

### 3.4. На весь экран и через несколько чартов

- **Затемнён весь экран**, «бесшовно» (владелец 08.10). Чарт шлёт маркер в канал скриншотов (повтор 1,5 с), CSS борда
  красит всё вокруг в `#7c8088` и прячет «⋯». Слой `body::after` поверх страницы в бою не появился (TR-16, [04](04-board-css.md)).
  Углы карточек под шторкой — прямые (`data-tsq`), иначе светлая дуга (TR-22).
- **Ведущий один** (самый большой чарт): шаги, порядок, карточка. Сосед — словарь целей `TOUR_T` и свой слой; на `dim`
  затемнён целиком, на `show` — вокруг цели и отвечает её прямоугольником (TR-11).
- **Шаги соседа решаются один раз, на вступлении** (`ask` → `keys`); нет ответа — тур по своим шагам (TR-12).
- **Карточка шага соседа ждёт ответа ≤ 400 мс**, чужой ключ не принимается — иначе прыгает (TR-13).
- Клавиши из соседа пересылаются ведущему; сосед на команду тура закрывает свои выпадашки; ведущий без тура шлёт `off`;
  сообщения несут префикс отчёта и ключ вкладки; протокол меняется во всех чартах одной поставкой (TR-15, TR-18, TR-19).
- Сосед готовит вид под тур (панель Adoption на старте встаёт на «Динамику» — её шаги не пропадают).

> Сверено с кодом: тур Adoption ведёт **каталог** (`pa-reports-body.chart.js`: `tourSteps`, карточка); шапка
> (`pa-head.chart.js`) — кнопка → `PA_TOUR_GO`, цели `period/opts/ca/help`, маркер `tourSig`, пересылка клавиш; панель —
> свои цели. Отличия от рекомендаций: карточка по `innerHeight`, вводная без живых чисел, нет «нажми — будет», шапка
> пересылает стрелки и из полей ввода, `data-tsq` — только у DL. В новом отчёте бери рекомендацию.

**Проверка (TR-21)** — скриптом на стенде: все шаги, цели ненулевые, карточка в окне, рамка у соседа, весь экран
`#7c8088` ± 3 и «как было» после Esc, клавиши из каждого чарта, 0 ошибок. Без прогона правки тура Adoption нашёл владелец.

## 4. Подсказки: один механизм

- **`title=` запрещён.** Подсказка — атрибут `data-tip` (HTML и SVG), разметку собирает **один конструктор**
  `{title, text, rows:[{label, value, color, dash}], note}`; он экранирует сам — `esc()` снаружи не зови.
- **Один узел** в `body` и один делегированный обработчик.
- **Поведение:** за курсором +14 / +18, у края — зеркально; на движении меняется позиция, `innerHTML` — при смене цели;
  между целями не гаснет, в пустоте — через 110 мс; гаснет на уход из iframe, прокрутку, `blur`. Цель — вся ячейка или
  колонка месяца во всю высоту (UI-11).
- **Содержание:** ≤ 3 значений и ≤ 2 сносок; значения одного кегля, база серая с пунктирным маркером, как в легенде.
- **Только если добавляет информацию**: обрезанное имя, как посчитано, состояние контрола («Сейчас: выключено»,
  «Отличается от умолчания»). У строк, где всё в колонках, подсказки нет; длинных URL нет.
- **Значок справки один** — «i» по наведению; длиннее трёх строк — панель.

> TeamPulse-макет: тултип +16 над курсором, гаснет сразу, край по `innerHeight`. В Proteus приводи к UI-11.

## 5. «Что видно в данных»

- **Отбор по порогам, без ИИ.** Один факт на метрику, первый сработавший: хуже ориентира ≥ 10 % → изменение к тому же
  месяцу год назад (10 % или 3 п. п.) → ухудшение 3 месяца подряд → заметно лучше ориентира. Плюс всплеск уходов (≥ 2×
  среднего и ≥ 3), сдвиг численности за год ≥ 10 %, ≥ 50 % отклонения в одном подразделении. Пороги — константами.
- **Важность** high (хуже KPI) / mid / good; ранжируй по людям сверх ориентира, а не по п. п.
- **Вид:** в чарте Proteus — свёрнуто строкой 42 px (первый факт с «…», «Ещё N ▾»), раскрытие — единственное
  намеренное изменение высоты; в HTML-отчёте — три видны, остальные «Ещё N». До 6–8 фактов.
- **Нет фактов — нет блока**: одна строка «Заметных отклонений нет.».
- **Факт ведёт к данным**: клик раскрывает строку метрики. Пункт ↔ график (TeamPulse): номерные отметки на полотне,
  наведение подсвечивает пару классами.
- Заглушки и малые выборки в факты не попадают. Выбор не сужает факты — подпиши «По всей области: …».

## 6. История по главам

**Зачем:** «экран отвечает на вопрос, а не показывает метрику» (TeamPulse 12.10). **Когда:** панель с несколькими
графиками одной темы.

- **Глава = под-вкладка.** Степпер: номер, вопрос («Сколько уходит?»), ответ («34 ухода за год»), точка светофора.
  **Шаги равной ширины** (выбор меняет фон, тень, вес); не влезает — «…» и подсказка; до номера не сворачивать.
- **Заголовок-вывод** — утверждение + фраза с цифрами из тех же рядов, что график.
- **Колонка выводов:** «Что важно», «Где сосредоточено» (клик выбирает строку), «Что сделать» — только при точке
  приложения сил (доля в метрике выше доли в людях на ≥ 8 п. п., одно подразделение хуже базы, отставание плана). Нет
  повода — нет пункта; кнопки «Дальше» нет. В узкой панели «Что сделать» дублируется под выводом.
- Акцент — полоса и подпись месяца-заметки; остальное **не приглушай** (13.10). Демо-главы выводов не получают.

## 7. Выбор, срез и кросс-фильтр глазами пользователя

**Выбор строк**
- **Клик — одна, Shift+клик — добавить, повторный — снять**; выделение текста строку не выбирает. Выбранная — фон
  `blue-bg` и полоса 3 px акцента слева.
- **Клик выбирает, а не уводит**: «Открыть юнит» — кнопкой у выбранной строки. Переход меняет юнит, не базу; над
  отчётом путь, «← Назад» (до 10) и «↑ Уровнем выше».
- **Прокрутка списка переживает клик и перерисовку.**

**Срез по клику** (внутри отчёта)
- Клик по строке разбивки или клетке матрицы пересчитывает KPI, сводную и **соседние** разбивки.
- **Срез не режет свою разбивку** и свою ось матрицы; один срез на разрез (вторая категория заменяет первую); уровни
  одного разреза — совместно.
- **Срез подписан плашкой у цифр**, которые изменил: без неё «191 → 59» — «поломка». Не протекает на базу, инсайты и
  другие вкладки.

**Фильтры и кросс-фильтр между чартами**
- **Выбор копится, уходит одной «Применить · N»**, видимой всегда; в выпадашках — «Закрыть ✕»; закрыл с набранным —
  плашка «Выбрано, не применено». «Будет N» — без запроса (UI-17). Вид — без запроса (MC-21).
- **Сосед узнаёт сразу** и пишет «Обновляю данные… N с» (с 2-й секунды); данные не исчезают, отчёт приглушён (MC-13, UI-23).
- **Жёлтая плашка — не раньше 45 с**, с причиной и действием; порог 9 с давал ложную тревогу в бою.
- **Строка применённых — одна, высота 34**: 1 пилюля во всю ширину; 2 — по ≤ 50 % и «Снять все»; 3+ — «Применено N».
  Без выбора — пусто (UI-20). Короткий разрез — пилюли, длинный — список с поиском от 8 значений.

## 8. «Год к году» и сравнение периодов

- **Динамика — только год к году** (TeamPulse 13.10): ось янв.–дек., этот год насыщенно, прошлый — бледно
  (`stroke-opacity .32`). Только линии; бары — для не-времени, мягкими тонами.
- Ориентир — цель KPI или база пунктиром, разрыв залит светофором. Встречные потоки — две линии на одной шкале,
  разные метрики — панели со своей шкалой от нуля.
- Период к периоду (Adoption, HRBP): к такому же прошлому окну; текущий — акцент с заливкой 8 %, прошлый — `#b4bdcc`.
- **Легенда — кнопки**: клик скрывает серию на всех графиках, последнюю скрыть нельзя («Клик — скрыть линию»).

## 9. Раскрыть / свернуть всё

- **Есть каретки в строках — есть общая каретка**, один компонент на отчёт, в строке ИТОГО (она первая) или в шапке.
- TeamPulse: `▸` раскрывает всё, `▾` — только когда раскрыто всё. Adoption (тысячи строк): `▸` — на уровень вглубь, `▾`
  при любом раскрытом — свернуть всё. Второй вариант — только когда полное раскрытие нечитаемо.
- Раскрывающаяся строка показывает каретку последней колонкой. Дерево — три уровня, «ниже ещё N», глубже — переход.

## 10. Переключатели метрик и вида

- **Состав метрик выбирает пользователь**, храни **скрытые** (новая метрика появится у всех). Опорные не выключаются.
  Пресеты («Всё · Текучесть · Найм · Минимум») + галочки. Скрытие не трогает графики смысла блока.
- Сегмент — для 2–5 видов, больше — список. **Активная вкладка не прыгает** (`data-text` + `::after`). Показать/скрыть
  панель — свитч с подписью на неподвижном месте.

## 11. Сортировка

- Клик по заголовку — колонка, повторный — обратно; **Shift+клик — следующий уровень** (до 3), номер у стрелки; обычный
  клик сбрасывает уровни (Adoption 09.10).
- Стрелка — только у активной колонки, абсолютом; пустые — вниз; без запроса; помощник одинаков во всех чартах.

## 12. Пустые состояния и ошибки поставки

- **Пустое — пусто**: нет выбора — ни плашки, ни подсказки. Пустой результат — что сделать.
- **Ошибка поставки — текстом в чарте с пунктом инструкции**: владелец консоль не видит (CJ-19).

  | Ситуация | Текст |
  |---|---|
  | `data` пуст | «Датасет не вернул строк: проверь датасет и лимит 50 000 (п. N)» |
  | нет колонок | недостающие + «добавь в „Измерения“ чарта (п. N)» |
  | нет `meta`, строк < `meta.rows` | «Ответ обрезан: N из M, поставь лимит 50 000 (п. N)» |
  | старый формат / штамп | «Датасет N-й поставки, чарт M-й — замени файл K» |
  | `ok = 0` | плашка доступа, не красная ошибка |

- Сосед не ответил — пометка с причиной в подзаголовке, не пустота.

## 13. Высота ячейки и раскладка

- Корень на всю ячейку, прокрутка внутри панелей (UI-09); «по экрану» — по видимой части iframe (UI-10).
- **Графики ужимаются под остаток высоты**, не под прокрутку, с порогами (Adoption: динамика от 200 px; TeamPulse:
  глава от 220); на большом экране — до ряда 800 px, ниже пусто.
- **Клик и появление не двигают вёрстку**: `getBoundingClientRect` до/после = 0 (UI-15). Горизонтальной прокрутки
  страницы нет.

## 14. Паттерны ✅ / Антипаттерны ❌

| ✅ Делай | ❌ Не делай | Почему |
|---|---|---|
| Тур по кнопке | Показ при первом входе, `localStorage` | Хранилища нет, вход не помнится |
| Страница затемнена CSS борда по маркеру | `body::after` поверх страницы | В бою не появился, швы видны |
| `data-tip` + конструктор | `title=`, ручные теги | Разный кегль и порядок |
| Факты по порогам | Фраза на каждую метрику | Не читают, шум |
| Срез подписан у цифр | Срез только выделением строки | Похоже на поломку |
| Клик выбирает, переход — кнопкой | Переход по клику | Уход из контекста |
| Одна «Применить · N» | Эмит на каждый клик | Запрос 5–20 с, гонка ответов |
| Секундомер, плашка с 45 с | Тревога через 9 с | Ложная тревога |
| `null`, разрыв линии | Ноль вместо пропуска | «Провалено» без повода |
| Текст на «ты» с действием | «Ошибка», «Отсутствуют данные» | Нечего делать |

## 15. Чек-лист UX перед сдачей

- [ ] База из фильтров и подписана; где KPI — базы нет; счётные не сравниваются; у изменения назван период.
- [ ] `null` — прочерк и разрыв; малые выборки не оценены; «демо» не в выводах.
- [ ] Тур только по кнопке; новый элемент — свой шаг; прогон скриптом: шаги, карточка в окне, весь экран, Esc, 0 ошибок.
- [ ] Ни одного `title=`; подсказки через конструктор, ≤ 3 значений, за курсором, в туре спрятаны.
- [ ] Тексты на «ты»; клик, бейдж, вкладка не сдвигают соседей.
- [ ] Срез подписан, не режет свою разбивку; без «Применить» — 0 запросов, с ним — один; плашка ожидания ≥ 45 с.
- [ ] Общая каретка у каждой таблицы с каретками; Shift-сортировка одинакова в чартах.
- [ ] Пустой результат говорит, что делать; ошибки поставки — текстом с пунктом инструкции.
- [ ] Ячейка выше экрана: модалка, карточка тура, «Применить» видны; ноутбук — вкладки без прокрутки.
