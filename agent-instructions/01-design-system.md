# 01. Дизайн-система отчётов и бордов Proteus

Для агента, который верстает или правит отчёт команды: TeamPulse (макет и пробник), Proteus Adoption, HRBP HUB,
любой новый борд. Старшинство: **решения владельца ниже → профиль Adoption (adoption:`DESIGN_SYSTEM.md` §16) →
ядро ДС (§1–15) → `proteus-playbook/11-ui.md`**. Где старый текст спорит с этим файлом, побеждает этот файл
(устаревшие места — в разделе 10). Новый борд собирай по профилю Adoption; значения TeamPulse даны, где отличаются.

## Главное в 10 пунктах

1. **Только Arial**: `Arial, Helvetica, sans-serif`, без `<link>` и `@font-face`; тултипу и слоям в `body` —
   стек явно. Веса только 400 и 700.
2. **Ступень между 400 и 700 — обводкой**: `#111318` + `-webkit-text-stroke:.25px currentColor`, только у названия
   строки в первом столбце таблицы.
3. **700 — только то, на что смотрят**: заголовок панели, число KPI, ИТОГО, выбранное. Остальное 400; иерархию
   ниже держат цвет, кегль, капитель.
4. **Кегли — только из шкалы ролей**: body 12,5 · note 11,5 · cap 10,5 · title 14,5 · hero 24. Текст для чтения
   не мельче 10,5. Новых кеглей не заводи.
5. **Числа**: `tabular-nums`, разряды тонким пробелом U+2009, минус «−» U+2212, компактно `1,2K` / `12K` /
   `3,4M`, нет данных — `—`.
6. **Светофор — два сигнала** (зелёный, красный), остальное серое, жёлтого в оценке нет. «Больше ≠ лучше» не
   окрашивай.
7. **Один акцент** — кобальт `#245FD4`. Цвета только в блоке токенов и рисовальном слое.
8. **Графики**: ось от нуля, оси Y нет, подпись у каждой точки и бара. Динамика — линией, разбивка — таблицей
   с полосой в ячейке, два бара рядом за период — нельзя.
9. **Подсказка одна**: кастомный тултип через `data-tip` и единый конструктор, едет за курсором; `title=` запрещён.
10. **Клик не двигает вёрстку** (`getBoundingClientRect` до и после). Тексты интерфейса — на «ты».

## 1. Принципы

- **Меньше решений — больше системы.** Отступ, кегль, радиус, вес — из шкалы. 7, 9, 13, 17 px рядом читаются
  как неаккуратность, а не иерархия.
- **Один смысл — один способ.** Направление несёт знак — стрелка не нужна; значение подписано у точки — ось Y
  не нужна.
- **Цвет — сигнал, а не украшение.** Серый = «повода вмешиваться нет».
- **Данные не искажаются вёрсткой.** Ось от нуля, одна шкала на сравниваемое, полоса от общего левого края.
- **Значение читается без наведения**; наведение добавляет контекст. **Интерактивность видна до клика**
  (каретка, подсветка); курсор-указатель — не признак.
- **Пустое — пусто.** Нет плашки «ничего не выбрано», нет плашки фактов без фактов.
- **Допущения честно**: придуманное — сноской, несравнимое — «не сравнивается», а не прочерком.
- **Один вид на все чарты борда**: общий CSS (таблицы, строка фильтров) — дословно одинаковый.

## 3. Типографика

### 3.1. Шрифт

```css
body{font-family:Arial,Helvetica,sans-serif;font-size:14px;color:var(--ink);background:var(--bg);
     -webkit-font-smoothing:antialiased}
button,select,input,textarea{font-family:inherit}
.xx-tip{font-family:Arial,Helvetica,sans-serif}   /* тултип в body: наследовать не от кого */
```
- Только Arial (владелец 09.10, подтверждено 14.10): у всех одинаково. На стенде Linux — Liberation Sans с теми
  же ширинами; без стека Arial скриншоты стенда не совпадают с боем.
- Нельзя: Inter, системный стек (`-apple-system`, `Segoe UI`), веб-шрифты, `<link>`, `@font-face`.
- SVG — тот же стек: `font-family="' + CFG.fonts.family + '"`.
- Иконочных шрифтов нет: инлайн-SVG и `▸ ▾ ▲ ▼ ↑ ↓ ×`. `↗` запрещён — съезжает с базовой линии.

### 3.2. Шкала кеглей по ролям

| Роль | px | Где |
|---|---|---|
| micro | 9,5 | служебное: строка медианы когорт; «i» в ⓘ и бейдж-счётчик — 9 |
| cap | 10,5 | шапки колонок (КАПИТЕЛЬ `.3px`), рубрики капсом (`.5px`), вторая строка ячейки (логин), ось X, подвал тултипа, «к маю» в дельте |
| note | 11,5 | подзаголовки панелей, подписи KPI, пилюли, вкладки, кнопки тулбара, дельты, сноски, текст тултипа |
| control | 12 | сегмент периода, переключатели шапки, пункты выпадашки |
| body | 12,5 | текст и числа таблиц, «Что видно в данных», значение в тултипе |
| lead | 13,5 | только TeamPulse: имя метрики One-pager |
| title | 14,5 | заголовок панели / карточки |
| head | 16 | только TeamPulse: заголовок блока страницы |
| hero | 24 | число KPI (`letter-spacing:-.4px`, `line-height:1.15`, `nowrap`) |

**SVG** (`CFG.fonts`): ось 10,5 (вторая строка — год/месяц — 9,5); подпись значения 11, плотная сетка (>16
колонок) 10; заголовок графика 13 (малый 12); легенда 12. Кегль не масштабируется: SVG рисуется по измеренной
ширине 1:1.

**Минимумы:**
- Текст, который читают, — **не мельче 10,5**. Тело таблиц — **12,5**, текст тултипа — **11,5**, значение
  тултипа — **12,5**.
- 9–10 px — только то, что можно не читать: ⓘ, бейдж, медиана, заголовок тултипа капителью (10), подпись
  значения в плотной сетке (10). 8 px — только глиф стрелки сортировки и номер уровня.
- Уменьшение на ступень владелец отменил (09.10: «читаю с напряжением»). Не помещается — прячь колонки и режь
  «…», а не уменьшай кегль.
- В коде Adoption остались 11, 13, 15 вне шкалы (метка тултипа, поиск, пустое состояние) — не размножай; новый
  код берёт ближайшую роль. Таблицы одного экрана — одного кегля.

### 3.3. Веса: 400 и 700

| Вес | Что |
|---|---|
| 400 | числа ячеек, текст, пояснения, шапки колонок, подписи KPI, пилюли, кнопки, неактивные вкладки, легенда, второй и дальше текстовые столбцы (даже имена), всё в тултипе |
| 400 + обводка | название строки в первом столбце (§3.4) |
| 700 | заголовок панели; число KPI; ИТОГО; **выбранное** — активная вкладка и сегмент, выбранный пункт выпадашки, нажатая кнопка-фильтр, название выбранной строки; начало месяца/года на оси X; «i» в ⓘ |

- 500 и 600 не пиши: Arial рисует 500 как 400, 600 как 700. В CSS — `var(--fw-body)` / `var(--fw-bold)`,
  в SVG — `400` / `700`. 800 нет.
- Выбранное — жирным (09.10: «слишком безакцентно»): на двух начертаниях фон и полоска без веса выбор не держат.
- Жирная вкладка не сдвигает соседей — резерв ширины невидимой копией:
  ```css
  .tab{display:inline-flex;flex-direction:column}
  .tab::after{content:attr(data-text);height:0;overflow:hidden;visibility:hidden;font-weight:700;pointer-events:none}
  ```
- **ИТОГО**: в TeamPulse строка целиком 700; в таблицах Adoption (14.10) подпись ИТОГО — обводкой, как названия,
  числа 400, строку держит линия 2 px. **Подпись значения на графике**: TeamPulse 700 (`VAL_W`), Adoption 400,
  новый борд — 400. В одном борде варианты не смешивай.

### 3.4. «Полужирный» обводкой — основной приём для названий строк

Ступени между 400 и 700 у Arial нет: без неё название отчёта сливается с логином под ним («мешанина», 14.10),
а 700 кричит. Решение владельца (14.10): почти чёрный и тонкая обводка цветом текста — на Retina выглядит как
полужирный, на обычном мониторе — чуть плотнее обычного.

```css
/* название строки — только первый столбец */
.t-table td.txt:first-child{color:var(--ink-name);-webkit-text-stroke:.25px currentColor}
/* внутри ячейки обводку снимаем со всего… */
.t-table td.txt:first-child *{-webkit-text-stroke:0}
/* …и возвращаем самому имени, кроме выбранной и приглушённой строки */
.t-table tr:not(.sel):not(.dim) td.txt:first-child .name{-webkit-text-stroke:inherit}
/* выбранная строка — 700 без обводки; вторая строка и пометки — 400 */
.t-table tbody tr.sel td:first-child{font-weight:700;-webkit-text-stroke:0}
.t-table tbody tr.sel td:first-child :is(.sub,.flag){font-weight:400}
```

- **Можно**: название в первом столбце — отчёт, коллекция, владелец, группа, сотрудник, ИТОГО (Adoption).
- **Нельзя**: логин и вторая строка ячейки, пометки, числа, шапки, второй и дальше столбцы; выбранная строка
  (700 без обводки — иначе каша); заголовки, KPI, кнопки, вкладки; текст мельче 12,5.
- Толщина — **не больше 0,3 px** (на 0,45 на 12,5 px забиваются «е», «а»). Цвет — `currentColor`.

### 3.5. Числа и форматирование

| Что | Как | Пример |
|---|---|---|
| Цифры | `tabular-nums` в таблицах, KPI, тултипах, пилюлях | — |
| Разряды / дробь | тонкий пробел U+2009 / запятая, обычно один знак | `2 968`, `1,8%` |
| Минус / плюс | `−` U+2212 ставит форматтер; `+` у изменений обязателен, ноль без знака | `−0,3`, `+3`, `0` |
| Единицы | `%` слитно; остальное через тонкий пробел | `+1,4 п.п.`, `27 дн`, `16,2 мес` |
| Компактно | от 1 000 — `1,2K`, от 10 000 — `12K`, от 10⁶ — `3,4M` | `5,2K` |
| Нет данных / нечем считать | длинное тире, не ноль | `—` |

```js
var THIN=' ', MINUS='−';
function nf(v,d){ if(v==null||!isFinite(v)) return '—';
  var s=Math.abs(v).toFixed(d||0).split('.'); s[0]=s[0].replace(/\B(?=(\d{3})+(?!\d))/g,THIN);
  return (v<0?MINUS:'')+s.join(','); }
function compact(v){ if(v==null) return '—'; var a=Math.abs(v);
  return a>=1e6? nf(v/1e6,1)+'M' : a>=1e4? nf(v/1e3,0)+'K' : a>=1e3? nf(v/1e3,1)+'K' : nf(v,0); }
```
Число KPI — одной строкой (`nowrap`): «5 182» рвалось по тонкому пробелу.

## 4. Цвет

**Светофор — оценка, два сигнала.**

| Состояние | Фон / текст | Марка |
|---|---|---|
| good — лучше ориентира | `--green-bg` / `--green-tx` | `#80cf9a` |
| bad — хуже ориентира | `--red-bg` / `--red-tx` | `#ef8c8c` |
| на уровне (±5%), зона риска, нет оценки | `--flat-bg` / `--muted` | `#c7c8cc` |

- ±5% — серое (`warn` в логике остаётся ради подписи «на уровне», цвет серый).
- Не окрашивай «больше ≠ лучше» и абсолютные величины. Выборку меньше 30 человек не оценивай — прочерк без цвета.
- Есть KPI — сравнение только с целью, нет — с базой; два ориентира рядом не ставь.
- Марка светофора — тон между фоном пилюли и её текстом, не ярче линии акцента. У HRBP HUB марки
  `#7fd2a5` / `#f59e9e` / `#d8dde4` — в одном борде один набор.
- Жёлтый — только в других каналах: важность факта «Что видно» (mid) и край дивергентной шкалы когорт.

**Категориальная — потоки и серии, не оценка.** Уход сиреневый, а не красный. Гамма одна на отчёт.

| Сущность | Линия (насыщенный) | Бар / полоса (мягкий) |
|---|---|---|
| одиночная метрика | `#245FD4` | `#7FA2E6` |
| найм, приход | `#14A38B` (насыщ. `#0E8A74`, внутр. `#0E95C7`) | `#66C8AE` |
| уход | `#8A4FD8` | `#A88AD9` |
| перевод внутрь / наружу | `#2E9BE0` / `#2448A8` | `#5FA5DE` / `#7F93CF` |
| итог, численность / прочее | `#c7c8cc` / `#686d76` | — |
| Adoption: новые / вернувшиеся / продолжающие / просмотры | `#245FD4` / `#AA77FF` / `#7FA3EA` / `#5b6478` | — |

**Порядковые — один тон разной светлоты** (светлое → тёмное): кобальт 5 ступеней `#D3E0FA #A9C1F2 #7FA3EA
#4A7BE0 #245FD4`, 4 ступени `#D3E0FA #8AAAEC #4A7BE0 #245FD4`. Для корзин частоты, воронки, сегментов, матрицы,
тепловой таблицы, календаря. Матрица и календарь — монохромно: «густо» не значит «плохо».

**Дивергентная** (когорты): жёлтый `#FFD758` ↔ белый ↔ кобальт `#8AAAEC`, по 3 ступени в сторону. Край каждой
стороны — максимальное отклонение своей стороны, поэтому крайняя ступень легенды всегда что-то подсвечивает.
Красный/зелёный тут читались бы как оценка.

**Правила для серий:**
- **Стек частей целого — ступени одного тона**: основание самое насыщенное, вверх светлее. Свой тон — только
  серии с собственным смыслом (Adoption: «вернувшиеся» `#AA77FF`), но не цвет светофора.
- **Линия яркая, бар мягкий**: насыщенный тон — тонкой линии; мягкая ступень того же тона — бару, полосе,
  водопаду, воронке (воронка — один тон на все этапы). Яркий бар «режет глаз».
- В одной таблице полосы одного цвета; разными цветами различаются таблицы, а не строки.
- Прошлый год — тем же цветом бледно (`stroke-opacity:.32`) или `#b9bdc6`, без подписей. База — серый пунктир
  `--bench`, цель — тёмный пунктир.
- Выбор людей (Adoption) — сиреневые пилюли `#f3ecff` / рамка `#e2d4ff` / текст `#5a2fc2`, отдельно от голубого
  выбора отчётов.

**Контраст** (с белым):
- Мягкие бары, марки светофора, `#AA77FF`, `#14A38B`, `#2E9BE0` — 1,7–3,2:1, поэтому у них **всегда подпись
  значения**.
- Марка ниже 2:1 растворяется. Светлые ступени (`#D3E0FA`, 1,3:1) — только заливка под числом или ступень
  стека, не одиночная марка.
- Текст: `--ink2` 8,8:1 · `--act` 5,7:1 · `--muted` 3,2:1 (только подписи) · `--muted2` 2,2:1 (не для текста,
  который надо прочесть).

Тёплое пятно в интерфейсе — одно, в кнопки не идёт.

## 5. Компоненты

`--shadow-lg`, подложка `rgba(20,28,45,.42)`. Прокручивается только тело, подвал с «Применить · N» виден всегда.
Esc и клик по фону закрывают (набранное сохраняется). Фильтры копятся и применяются одной кнопкой.

**Тултип — единый механизм.**
- Один узел в `body`, `position:fixed`, стек шрифта и цвета — явно. Содержимое — конструктор
  `{title, text, rows:[{label,value,color,dash}], note}`, сам экранирует (снаружи `esc()` не звать). Цель —
  атрибут `data-tip`.
- Курсор +14 / +18, едет за курсором, у края окна отражается. `innerHTML` — только при смене цели; между соседями
  не гаснет, в пустоте гаснет через 110 мс.
- Вид: радиус 9, padding 7 10, max-width 260, рамка `--line`, `--shadow-tip`. Заголовок 10 КАПИТЕЛЬ `--muted`;
  метка note `--muted`; значение body 12,5 `--ink` справа, `tabular-nums`; база — серым с пунктирным маркером;
  подвал cap над линией `--line2`.
- Значения одного кегля; значений ≤ 3, сносок ≤ 2. Только если добавляет информацию: не повторяй строку, не клади
  длинные URL.

**Легенда.** В правом углу заголовка графика или карточки (заголовок слева, не накладываются). 12, `--ink2`, 400;
маркер повторяет марку (прямоугольник — серия, пунктир — база). Интерактивна: наведение гасит чужие
(`opacity:.18`), клик / Enter / Space выключает серию; последнюю выключить нельзя, водопад заблокирован;
выключенная уходит из шкалы и подсказки.

**Пустое состояние и ожидание.** Карточка, текст `--muted` по центру, заголовок `--ink`; говорит, что сделать:
«Сними один из фильтров в шапке», а не «Нет данных». Пустых плашек ради симметрии нет. При ожидании данные не
пропадают (`opacity:.55`), строка «Обновляю данные… N с»; тревожная плашка — не раньше 45 с.

**Справка ⓘ.** Один вид на борд: круг 14 px, рамка `--muted2`, «i» 9 px / 700 `--muted`, hover — рамка и «i»
`--act`. Раскрывается наведением. Длиннее трёх строк — уже панель или модалка.

**«Что видно в данных».** Свёрнуто — строка 42 px: иконка 20×20, первый факт с «…», справа «Ещё N ▾»; раскрытие
вниз, отступ слева 44. Точка важности 7 px: high красная, mid `#d69a00`, good зелёная. Факты — правилами по
порогам, без шаблонов и ИИ: отклонение ≥ 10%, ухудшение 3 месяца подряд, ≥ 50% в одном срезе. Нет фактов —
нет плашки.

## 6. Визуализация данных

| Задача | Вид |
|---|---|
| Динамика метрики | линия с подписями (TeamPulse — только «год к году», янв.–дек.) |
| Пара встречных потоков | две линии на одной шкале от нуля |
| Несколько метрик за период | панели друг под другом: общая ось X, у каждой своя шкала от 0 |
| Разбивка по атрибуту | таблица с полосой в ячейке (не кольцо, не горизонтальный бар) |
| Два разреза сразу | матрица — таблица с монохромной заливкой |
| Состав итога / этапы | водопад / воронка, мягкие тона |
| Плотность по дням | календарь-хитмап, монохромный |
| Тренд в строке | спарклайн-линия `#8a909c`, точки — светофором, последняя крупнее |
| Удержание когорт | кривая удержания над таблицей когорт с дивергентной шкалой |

Столбики — только где это не сравнение двух лет: стек пользователей по периодам (Adoption), водопад, воронка.

**Оси.**
- Ось значений от 0 всегда: низ — константа, считается только верх (1 / 1,2 / 1,5 / 2 / 2,5 / 3 / 4 / 5 / 6 / 8 /
  10 × 10ⁿ). Оси Y, засечек, сетки нет — только линия нуля.
- Ось X одинакова во всех видах: линия 1 px `rgb(155,164,181)`, подписи 10,5; начало месяца/года — 700 `#3a3f4a`,
  вторая строка — год/месяц. Колонка уже 31 px — месяцы через один, январь всегда.
- Граница года — пунктир ровно на высоту области построения. Пороги цели — справа от полотна, не поверх точек.
- Нет значения — разрыв линии, а не ноль.

**Подписи значений.** У каждой точки и столбика, `#2b2b2b`, 11 (плотная сетка 10). Белая обводка 3 px: надёжнее
вторым `<text>` под заливкой (TeamPulse, 3,2); `paint-order:stroke` (Adoption) проверь в Safari. Налезают —
через одну, отсчёт от последней (она подписана всегда), остальные — в подсказку.

**Единая геометрия** — общие константы, не значения на месте: `AXIS_H` 30 · `HEAD_GAP` 8 · `PAD_X` 6 ·
`VAL_SZ` 11 · `VAL_DY` 9 · `LBL_ROOM` 26 (Adoption: воздух над марками ×1,3, плотная ×1,22) · `STACK_GAP` 26 =
`--chart-gap` · `DRAW_MS` 760. Столбик: зазор 8, ширина 3…72 px; скругляется дальний от нуля край. Графики
ужимаются под остаток высоты (поле рисования ≥ 64 / 40 px), а не уходят под прокрутку.

**Интерактив.** Хит-зона — вся колонка периода во всю высоту (`fill-opacity:0`, не `fill:none`). Каждая марка
несёт `data-s="<серия>"` отдельным атрибутом. Наведение на месяц подсвечивает связанные пункты «Что видно»
и наоборот (остальные `opacity:.45`).

**Анимация** — только при рендере с новыми данными (клик по строке, смена периода); не при ресайзе, наведении,
клике по легенде. Столбики растут от оси 480 мс волной (+12 мс на колонку); линия рисуется 760 мс слева направо,
заливка открывается `clipPath`; точки и подписи проявляются; полосы растут слева; пунктир базы проявляется.
В Proteus — Web Animations из JS (`fill:'backwards'`). `prefers-reduced-motion` — без анимации; спарклайн
не анимируется.

**«Год к году»** (TeamPulse по образцу HRBP HUB). Ось янв.–дек.; этот год — насыщенно с подписями, прошлый —
бледно той же формой, подписан одной точкой (последний закрытый месяц) серым. «Вы здесь» — тонкая вертикаль
и жирный месяц на оси. Ориентир один и только у текущего года. Прогноз — пунктир того же цвета до декабря, полая
точка, «прогноз X». Номерные отметки пунктов «Что видно» — кружок 16 px (наведение — 20). Накопительные
стартуют с нуля в январе.

## 7. Раскладка, адаптив, доступность, тон

**Раскладка.** Карточка вровень с ячейкой на холсте `#f6f6f6`, без «страницы в странице». Корень — flex на 100%
iframe, фиксированных высот у панелей нет, прокрутка внутри. Шапка листа — одна строка ~64 px. «Таблица |
визуализация»: каталог ~38%, пара панелей одной высоты, верх вровень, разделитель 30–80%. Отступы из шкалы,
исключения названы (`chart-gap` 26, отступ «Что видно» 44). Клик, бейдж, раскрытие не меняют высоту строк;
единственное намеренное изменение — раскрытие «Что видно».

**Адаптив.**
- Брейкпоинты — по замеру, не круглыми числами; порог колонок = порог фиксированной высоты.
- Ячейка Adoption ≤ 760 — поля KPI 10. Уже 1 100 — одна колонка классом на корне, не `@media` по окну.
- Большой экран: графики растут до ряда ноутбука (800 px), ниже пусто, блоки не центрируются. Борд ≤ 2 400 px.
- TeamPulse-макет: каркас `--shell:1760px`, пороги 1240 · 1120 · 1100 · 900 · 780 · 480.
- Телефон: таблица прокручивается внутри обёртки; горизонтальной прокрутки страницы нет.

**Доступность.** `lang="ru"`; `:focus-visible` (outline `--act`); кликабельная строка — `tabindex="0"`,
`role="button"`, Enter/Space = клик; `aria-expanded` у раскрываемого; `aria-label` у иконки-кнопки, декор
`aria-hidden`; Esc закрывает всё; `prefers-reduced-motion`. Текст для чтения — не светлее `--muted`.

**Тон.** На «ты» (09.10): «сними выбор», «наведи», «твой логин». Коротко, по-человечески; подпись называет
действие («подробнее», «свернуть»), а не состояние. Всегда проговаривай: с чем сравнение («+3 к маю»), что фильтр
меняет и что нет, где данные допущены, почему метрика не окрашена. Не пиши «Ошибка» / «Внимание» без действия,
нераскрытые аббревиатуры, одно и то же дважды. Подсказка: заголовок — что это; фраза — смысл; числа — строками;
оговорки — сноской.

## 8. Паттерны и антипаттерны

**✅ Делай так**
- ✅ Название — обводка `.25px` + `#111318`, логин под ним — cap `--muted`: ступень видна без третьего веса.
- ✅ Выбранная строка — 700 + фон `--blue-bg` + полоса 3 px `::before`: в Arial фон без веса выбор не держит.
- ✅ Иерархия таблицы цветом: `--ink` (первый столбец) → `--ink2` (числа, текст) → `--muted` (шапки, вторая
  строка).
- ✅ Кегль, отступ, радиус — ролью из `CFG`/токена; один профиль на все чарты борда.
- ✅ Не помещается — прячь колонки и режь «…» с подсказкой; кегль не трогай.
- ✅ У мягкого бара всегда подпись: контраст ниже 3:1.
- ✅ Порядковые данные — ступени одного тона: «больше — темнее» читается без легенды.
- ✅ Общий CSS таблиц и фильтров — дословно во всех чартах борда, со сверкой («таблицы по-разному
  отформатированы»).
- ✅ Вид проверяй замерами (`getBoundingClientRect`, DOM-проба), а не глазом: сжатый скриншот врёт.

**❌ Не делай так**

| ❌ | Почему |
|---|---|
| Inter, системный стек, веб-шрифт, `@font-face` | у коллег другая картинка и ширины; владелец вернул Arial (14.10) |
| `font-weight:500/600` | Arial рисует их как 400/700: в коде ступень есть, на экране нет |
| Обводка > 0,3 px или на тексте < 12,5 | забиваются «е», «а» |
| Обводка на числах, логинах, выбранной строке | шум; поверх 700 — каша |
| Всё полужирное: имена, числа, шапки, итог | выделять становится нечем |
| Кегль «на ступень меньше», 8–9 px для текста | «читаю с напряжением» (отменено 09.10) |
| Новый кегль «между 12 и 13» | полпикселя — неаккуратность, а не иерархия |
| Жёлтый / третий сигнал в светофоре | приходится выбирать, к чему присматриваться |
| Окрашивать абсолютное и «больше ≠ лучше» | цвет врёт об оценке |
| Стрелка `↑↓` в дельте | дублирует знак; `↓` у текучести и у найма значат разное |
| Урезанная ось; ось Y при подписях | 6,1–6,9% выглядит обвалом; лишние чернила |
| Два бара рядом; кольцо или бар для разбивки | не сравниваются; доля по числу точнее угла |
| Яркий бар, бледная линия | бар «режет глаз», пастельная линия некрасива |
| Разные цвета строк одной разбивки | цвет выглядит смыслом, которого нет |
| `title=`; свой тултип в каждом месте | системный вид и задержка; строки расходятся по кеглю |
| Разный кегль значений в подсказке | размер кодирует порядок в массиве, а не смысл |
| Литерал `#rrggbb` в разметке экрана | палитра расползается |
| `#f4f5f7` или тень у карточки на борде | «серая заплатка», тени на краях |
| Плашка «ничего не выбрано» | занимает строку и ничего не сообщает |
| Ноль вместо «нет данных»; дефис вместо «−» | ноль читают как провал; минус ставит форматтер |
| Жирная вкладка без резерва ширины | соседи прыгают при клике |
| «Вы» в новых текстах | решение владельца — «ты» |

- [ ] Блоки CSS «ТАБЛИЦЫ» и «ВЫБРАННЫЕ ФИЛЬТРЫ» совпадают во всех чартах борда.
- [ ] Горизонтальной прокрутки страницы нет на 768–2560; карточки вровень с ячейками, теней на борде нет.
