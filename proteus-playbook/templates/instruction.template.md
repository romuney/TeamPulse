## 1. Датасеты

1. Proteus → Datasets → новый виртуальный датасет, база **<база>** (та же, что у <прежнего датасета>), имя `<имя>`.
2. SQL — файл 2 целиком: в файле Ctrl+A → Ctrl+C, в поле SQL Ctrl+A → Ctrl+V. Так же `<имя>_flt` — файл 3.
3. Save. Сохранение исполняет запрос с пустыми фильтрами под вашим логином — секунды.
   - **Готово, когда:** сохранился без красного; колонок ровно 5: `role, k, v, n, j`.
   - «Некорректный SQL запрос: →…←» — прислать фрагмент между стрелками; проверьте, что файл из этой поставки целиком.
4. Меняли SQL у существующего датасета и список колонок изменился: «Синхронизировать столбцы» → в каждом чарте на нём
   удалить покрасневшие поля «Измерений», добавить новые → Update chart → Save. Колонки не менялись — «Измерения» не
   трогать.
5. Вкладка «Настройки» — у обоих датасетов одинаково:
   - «Время жизни кэша» — пусто или `0`: это 12 часов (в ответах чартов — `cache_timeout: 43200`). Дольше не ставить:
     связанные чарты должны показывать данные одной даты. **`-1` кэш НЕ выключает** — не ставить.
   - «Фильтры автозаполнения» — выключено, «Предикат запроса автозаполнения» — пусто: Proteus читает его, когда решает,
     чей кэш.
   - «Описание» — номер поставки (`поставка <N>`): видно, что стоит; при замене SQL это ещё и правка, после которой
     Proteus не отдаёт старый ответ из кэша.
   - «Настроить доступы» — как у прежних датасетов отчёта.

### 3.3 CSS борда (обязательно)

«Редактировать дашборд» → CSS → удалить прежний блок этого отчёта — от строки «<Отчёт> — CSS борда · НАЧАЛО» до
«… · КОНЕЦ» → вставить файл 6 целиком в конец → «Сохранить» → Cmd/Ctrl+Shift+R. Чужой CSS не трогать. id чартов в
файле уже стоят: <id> — <чарт>, <id> — <чарт>; на другом борде у чартов другие id — пришлите их, соберу файл заново.

Блоки: 1 — ячейки без белых рамок и теней, чарт на всю ячейку, карточка на загрузке той же формы, что чарт; 2–3 —
выпадашка и подсказки панели выходят за панель; 4 — пока данные идут, вместо «Не было получено данных по этому запросу» —
белые карточки, значок и «Загружаю…»; 5 — вкладки в стиле чартов, через 40 px, значок ссылки сразу за названием
(действует на все вкладки борда); 6 — поля: от шапки до вкладок <12> px, по бокам и снизу <24>, от вкладок до чартов 16;

число в блоке 7 можно подстроить самому — пришлите потом фото CSS или скажите числа: перенесу их в исходник, иначе
следующий файл их затрёт. Красные «!» редактора у строк с `:has(…)`, `:not(… *)` и `max(…)` — линтер их не знает, на
работу не влияет.
- **Готово, когда:** нет белых рамок и теней у краёв чартов; при Cmd+Shift+R — карточки «Загружаю…» без картинки «Не было
  получено данных», а появились данные — размер и углы карточек не меняются; выпадашка панели открывается справа поверх
