# Team Pulse — сводка графиков (для объединённого дашборда)

Сравнение двух дашбордов по **содержанию графиков** (без метрик), чтобы спланировать объединённый дашборд.

- **HQ** — дашборд 34136 «Team Pulse: Управленческая структура HQ» (`Team Pulse HQ - метрики.md`)
- **УС** — дашборд 34661 «Team Pulse: Управленческая структура» (`Team Pulse УС - метрики.md`)

Легенда: **ОБА** = блок есть в обоих дашбордах (дублируется), **HQ** / **УС** = только в одном.
