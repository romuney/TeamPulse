# TeamPulse Hub — что куда вставлять

Отчёт в Proteus собирается так же, как HRBP HUB: **таблицы ClickHouse → один датасет →
один чарт**, и, если существующих таблиц не хватит, — ноут Helicopter со своими витринами.
Всё, что в макете было шапкой, вкладками, таблицей подразделений и графиками, будет жить
в одном чарте. Как отчёт должен выглядеть и работать — макет (`index.standalone.html`,
он же GitHub Pages) и правила в `AGENTS.md`; откуда берутся данные — `SOURCES.md`.

## Файлы

| Файл | Куда вставлять | Сейчас |
|---|---|---|
| `0а. SQL Lab — структура таблицы ClickHouse.sql` | SQL Lab в Proteus (или DBeaver, clickhouse-client): запросы по одному, ответы — мне | **готов — шаг 0** |
| `1. Helicopter — ноут TeamPulse Hub.yaml` | Helicopter → ноут «TeamPulse Hub» → импорт YAML | появится, если готовых таблиц не хватит |

| `5. SQL Lab — проверки после выгрузки.sql` | SQL Lab: проверить данные до заведения датасета | вместе с датасетом |

Номера закреплены заранее и между поставками не меняются: «замените файл 3» всегда значит
чарт. Файл с буквой (`0а`, `1а`) — дополнение к своему номеру.

## Шаг 0 — покажите структуру таблиц ClickHouse

1. Откройте `0а. SQL Lab — структура таблицы ClickHouse.sql`, замените во всём файле
   `my_db` на имя базы и `my_table` на имя таблицы (Ctrl+H).
2. Выполняйте запросы **по одному**: выделите запрос → Run (Ctrl+Enter).
3. Ответ каждого — «Скопировать в буфер» или CSV — пришлите в чат с номером запроса.
   Таблиц несколько — прогоните файл для каждой.
4. Если SQL Lab не пропускает `SHOW CREATE TABLE` (запрос 3) — пропустите его, хватит 1 и 2.

**Персональные данные не присылайте.** Запросы 1–5 их не показывают — там имена колонок,
типы и счётчики. В запросах 6 и 7 перечислите в `EXCEPT` свои колонки с ФИО, почтой,
логином, табельным номером и зарплатой: их имена видны в ответе на запрос 2. `EXCEPT`
молча пропускает имя, которого в таблице нет, поэтому `fio, email` в файле — только
пример. Ключ сотрудника в запросе 7 заменён хешем: видно, что строки одного человека
повторяются, а кто он — нет.

**Что я сделаю с ответами:** сопоставлю колонки с метриками отчёта (`SOURCES.md` §7 —
паспорта метрик, §17 — что нужно новым метрикам), найду зерно таблицы и то, чего в ней не
хватает, и напишу датасет — файл 2.
