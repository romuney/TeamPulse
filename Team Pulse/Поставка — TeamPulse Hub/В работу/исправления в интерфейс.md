# Новая итерация: визуальная доработка вкладки «Ревью»

## Цель

Доработать представление данных на вкладке «Ревью»:

1. Заменить текстовые названия оценок соответствующими картинками.
2. В распределении по специализациям показывать топ-10 и добавить кнопку «Остальные» по аналогии с другими вкладками.
3. Привести визуальные стили вкладки к общему оформлению дашборда.

## Общие ограничения

- Не менять расчёты, состав выборки и правила применения фильтров.
- Не менять числовые значения оценок и их порядок.
- Использовать существующие ресурсы, компоненты и стили проекта.
- Не создавать отдельный визуальный стиль для «Ревью».
- Если нужный ресурс или правило не найдено, зафиксировать необходимость уточнения, а не подменять его произвольным решением.

## 1. Заменить текстовые названия оценок картинками

### Требование

На вкладке «Ревью» вместо текстовых названий оценок показывать соответствующие картинки.

Название файла картинки соответствует названию оценки. Проверить фактические имена и расположение файлов в проекте.

### Где применить

Во всех местах вкладки, где отображается конкретная оценка:

- заголовки столбцов таблиц распределения;
- предыдущая и текущая оценки в переходах;
- первые полученные оценки;
- подписи и легенды графиков;
- тултипы и другие элементы, отображающие название оценки.

### Правила соответствия

- Сопоставлять оценку с картинкой по фактическому названию.
- Использовать единое соответствие во всех компонентах.
- Не определять соответствие по порядку файлов в каталоге.
- Не менять шкалу оценок и её сортировку.
- Не заменять картинками количества сотрудников, проценты и другие числовые показатели.

### Представление переходов

Переход между оценками отображать в виде:

**картинка предыдущей оценки → картинка текущей оценки → количество сотрудников**

Для первой оценки:

**обозначение отсутствия предыдущей оценки → картинка первой оценки → количество сотрудников**

Не подбирать изображение для `n/a` самостоятельно, если соответствующего ресурса нет.

### Визуальные требования

- Использовать одинаковые размеры картинок в однотипных элементах.
- Сохранять пропорции изображений.
- Не обрезать содержимое.
- Выравнивать картинки относительно соседних значений и заголовков.
- Не допускать неоправданного увеличения высоты строк или ширины столбцов.
- Проверить читаемость таблиц и графиков на поддерживаемых размерах экрана.

### Доступность и обработка ошибок

- Добавить каждой картинке `alt` с названием оценки.
- Сохранить возможность узнать название оценки через подсказку.
- Не выводить сломанные изображения.
- Если ресурс отсутствует, показать текстовое название как резервный вариант и зафиксировать недостающий файл.
- Если библиотека графиков не поддерживает изображения в нужном месте, использовать возможности существующих компонентов или явно зафиксировать ограничение.

### Ожидаемый результат

Оценки представлены картинками единообразно на обеих подвкладках «Ревью», при этом их смысл остаётся понятным пользователю.

## 2. Распределение по специализациям: топ-10 и «Остальные»

### Требование

В таблице распределения оценок по специализациям по умолчанию показывать топ-10 специализаций.

Добавить кнопку **«Остальные»**, повторяющую существующую механику других вкладок.

### Перед реализацией

Найти в проекте существующий блок с кнопкой «Остальные» и переиспользовать:

- компонент или обработчик раскрытия;
- оформление кнопки;
- расположение;
- поведение при раскрытии и сворачивании;
- подпись кнопки в раскрытом состоянии;
- правила изменения состояния при фильтрации и переходах между вкладками.

Не создавать новую механику, отличающуюся от уже используемой.

### Правило топ-10

- Формировать топ-10 после применения действующих фильтров.
- Ранжировать специализации по количеству сотрудников в текущей выборке таблицы.
- Использовать исходные количества, а не округлённые значения или доли.
- Для одинаковых количеств использовать стабильный порядок, принятый в проекте.
- Если существующая аналогичная таблица использует другое согласованное правило ранжирования, применить его единообразно.

### Поведение кнопки

- По умолчанию показывать первые 10 специализаций.
- Если специализаций больше 10, показывать кнопку «Остальные».
- По нажатию отображать оставшиеся специализации по механике других вкладок.
- Если специализаций 10 или меньше, кнопку не показывать.
- Не создавать агрегированную строку «Остальные» вместо раскрытия списка, если такой логики нет в существующем компоненте.

### Сохранение данных

Ограничение топ-10 относится только к отображению строк.

Оно не должно:

- исключать остальные специализации из исходной выборки;
- менять расчёты других блоков;
- менять значения в строках таблицы;
- менять знаменатели долей;
- пересчитывать общие итоги только по видимым строкам.

В раскрытых строках сохранить все столбцы таблицы:

- количества по каждой оценке;
- долю сотрудников с оценками `0–1`;
- долю сотрудников с оценками `3–4`.

### Ожидаемый результат

По умолчанию таблица компактна и показывает топ-10 специализаций. Остальные доступны через привычную пользователю кнопку без изменения расчётов.

## 3. Привести визуальные стили «Ревью» к остальным вкладкам

### Требование

Проверить оформление обеих подвкладок «Ревью» и устранить отличия от общего визуального языка дашборда.

### Что проверить

#### Навигация

- Основную вкладку «Ревью».
- Подвкладки «Кого оцениваем» и «Как оцениваем».
- Активные, неактивные, hover- и focus-состояния.
- Размеры элементов, отступы и выравнивание.

#### Типографика

- Шрифты.
- Размеры и насыщенность заголовков.
- Цвет основного и второстепенного текста.
- Межстрочные интервалы.
- Оформление пояснений и подписей.

#### Карточки и блоки

- Фон.
- Скругления.
- Границы и тени.
- Внутренние и внешние отступы.
- Расстояния между блоками.
- Выравнивание по общей сетке.

#### Таблицы

- Оформление заголовков.
- Высоту строк.
- Отступы ячеек.
- Выравнивание чисел и текста.
- Разделители и фон строк.
- Hover-состояния.
- Горизонтальную прокрутку.
- Оформление итогов, если они предусмотрены.
- Размещение картинок оценок.

#### Графики

- Палитру.
- Шрифты и подписи.
- Оси и сетку.
- Легенды.
- Тултипы.
- Размеры и отступы.

#### Кнопки и состояния

- Кнопку «Остальные».
- Состояния загрузки.
- Пустые выборки.
- Ошибки.
- Состояния наведения и клавиатурного фокуса.

### Принципы реализации

- Переиспользовать общие компоненты и CSS-классы.
- Использовать существующие дизайн-токены.
- Удалить необоснованные локальные переопределения стилей.
- Не копировать общие стили в отдельные версии для «Ревью».
- Не менять оформление остальных вкладок ради исправления одной.
- Проверить, что изменения общих компонентов не вызвали регрессий.

### Ожидаемый результат

«Ревью» воспринимается как часть единого дашборда: навигация, таблицы, графики, кнопки и состояния оформлены так же, как на остальных вкладках.
