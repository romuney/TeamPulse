Для ноутбука, который уже стоит (финальный вариант Адель «TeamPulse Hub_20.10_final» с правками поставки 54):
заново **не импортировать** — заменить код одного параграфа. Новая установка — целиком файл 1, в нём то же самое.

Что нового против поставки 54 — шаг 10 «переходы»:

- **перевод — по флагам источника** (методология переводов, папка «переводы»): юнит — `lvlN_mngt_unit_in/out_trsf_flg`,
  покраска — `transfer_to/out_hq_flg`, IT-код — `transfer_to/out_it_flg`, штат — `transfer_to/out_employment_relation_type_flg`,
  тип численности — `transfer_to/out_active_type_flg` и переход кандидата или стажёра. Флаг «в» — на первом дне в новом
  состоянии, «из» — на последнем дне в старом, поэтому перевод датируется днём прихода: перевод «из» в последний день месяца
  уходит в следующий месяц вместе с «в» — как в методологии, и в численность конца месяца человек попадает один раз;
- **найм — по дню события** (вид `h`): срез найма — на день найма, а не на конец месяца. Тогда найм, отток и переводы
  сходятся с численностью и у тех, кому срез сменили в месяц найма;
- кандидаты учебных юнитов и стажёры (`in_ok = 0`) — найм только на активной численности, на всей — перевод (методология
  переводов: их исключают «в активной численности»);
- **смены без флага** — отдельными видами `x…` для сверки (`xi`/`xo`/`xs` — часть перехода без флага, `xa` — появился без
  найма, `xd` — пропал без увольнения). На чистых данных их нет; если есть — это и есть «прочее» водопада. Проверка — файл 5а.

Остальное — как в поставке 54 (правки Адель против падения по объёму, путь юнита целиком). «to click» не меняется.

## build_hub_detect — заменить код целиком

Параграф `build_hub` над ним (черновик с закомментированным старым кодом) можно выключить: `build_hub_detect`
определяет ту же функцию позже и переопределяет её. Потом — запустить ноутбук с этого места (`build_hub_detect`
→ `EXEC build_hub` → `hub checks` → `to click`).

```python
# =============================================================================
# Блок 4 — таблицы TeamPulse Hub: всё, что отчёту нужно, считается здесь.
#   teampulse_hub_meta    1 строка: последний месяц (и текущий незакрытый), дата данных, сетка, корень, юнит по умолчанию
#   teampulse_hub_unit    узлы нынешней структуры (по ключам юнитов): родитель, уровень, имя,
#                         число подразделений, путь ключами от корня, логин руководителя
#   teampulse_hub_series  узел × месяц × срез (покраска, IT, штат, тип численности): численность, активная, ССЧ,
#                         найм (как в методологии DD: найм в компанию + перевод из учебной группы
#                         в боевую + перевод стажёров в штат), увольнения, regret, переводы через
#                         границу узла, мониторинг, посещаемость, T-рост. Узел несёт всё своё
#                         поддерево
#   teampulse_hub_mix     узел × срез (с типом численности) × разрез × значение: численность последнего
#                         месяца по атрибутам, увольнения с начала года по причинам и др., найм
#                         с начала года по каналу / грейду / специализации
#   teampulse_hub_trf     переходы людей: узел × месяц × вид (вошёл / вышел / остался) × срез до и
#                         после — датасет считает из них переводы под выбранные фильтры
#   teampulse_hub_vacancy узел × месяц × разрезы вакансии (канал, причина, уровень кандидата и
#                         позиции, специализация, статус): открыто, закрыто, новые, срок закрытия
#   teampulse_hub_ai      узел × месяц: WAU AI-инструментов и проникновение (по юниту и компании)
# Виртуальный датасет отчёта не кешируется и на каждый запрос только выбирает узлы ответа:
# дерево, история в нынешней структуре, ССЧ, переводы и разрезы готовы здесь.
# Источник — таблица человек × месяц × юнит (build_all_metrics + перформанс, посещаемость,
# T-рост), до group_and_sum_metrics: разрезы и переводы считаются по людям.
# =============================================================================
import datetime as dt_
from dal_client import query as dal

HUB_ALL = 'all'          # ключ общего корня, если корней в структуре несколько
# Где брать логин руководителя юнита (19.10: под именем юнита в окне настройки и поиск по нему,
# как в HRBP HUB): первая таблица, где есть все колонки, — источник TP 2.0, иначе структура
# сотрудников (её берёт HRBP HUB). Нет ни одной — логин пустой, отчёт работает.
HUB_HEAD_SRC = [('usr_cross_data.hr_executive_proteus', 'calendar_dt'),
                ('prod_v_emart.mdm_employee_structure_d', 'business_dt')]
HUB_HEAD_COLS = {'mdm_employee_rk', 'management_head_flg', 'ad_login', 'management_head_ad_login'}


def _hub_q(sql: str):
    return dal.get_df(datasource='gp', query=sql)


def _hub_run(steps, label: str = '', debug: bool = False):
    """Шаги по одному; упал — номер и начало текста упавшего шага (21.10, Адель). debug — только печать"""
    for i, sql in enumerate(steps, 1):
        if debug:
            print(sql)
            continue
        try:
            _hub_q(sql)
        except Exception as e:
            print(f'[FAIL] {label}: шаг {i}/{len(steps)}')
            print(str(e)[:300])
            print('--- SQL (первые 800 символов) ---')
            print(sql[:800])
            raise


def _hub_clean(col: str) -> str:
    """значение разреза: «-» и NULL — пустая строка, табы, переводы строк и «|» — пробелы и «/»
    (разделители ответа датасета)"""
    return f"coalesce(nullif(translate({col}::text, E'\\t\\n|', '  /'), '-'), '')"


def _hub_head_src():
    for t, d in HUB_HEAD_SRC:
        try:
            if HUB_HEAD_COLS | {d} <= _source_cols(t):
                return t, d
        except Exception:
            continue
    return None, None


def build_hub(
    source: str = 'all_metrics_with_performance_and_office_traffic_and_grt',
    prefix: str = 'teampulse_hub',
    daily_source: str = 'usr_cross_data.hr_executive_proteus',
    vacancy: str = 'structure_x_vacancy',
    ai_source: str = 'usr_mlpa.ai_bi_all_copilots_usage_digest_monthly',
    n_levels: int = 11,
    staff_value: str = 'Штатный сотрудник',
    debug: bool = False,
):
    src, p = _qualified(source), _ident(prefix)
    cols = _source_cols(src)
    has = lambda c: c in cols
    lv = [i for i in range(1, n_levels + 1) if has(f'lvl{i}_rk') and has(f'lvl{i}_nm')]
    if not lv:
        raise ValueError('нет lvlN_rk: build_all_metrics должен выводить ключи уровней')
    rk_arr = 'ARRAY[' + ', '.join(f's.lvl{i}_rk::text' for i in lv) + ']'
    path_rk = f"array_to_string(({rk_arr})[1:s.leaf_lvl], '|')"
    cut = lambda c, alias: f"coalesce(nullif(s.{c}::text, ''), '-') AS {alias}" if has(c) else f"'-'::text AS {alias}"
    num = lambda c: f'coalesce(e.{c}, 0)' if has(c) else '0'
    snum = lambda c: f'coalesce(s.{c}, 0)' if has(c) else '0'
    dist = lambda key: f'distributed by ({key})'
    steps = []

    # 1. последний месяц — последний в источнике, и текущий незакрытый тоже (20.10, заказчик: «показывать
    #    текущий месяц, как в HRBP HUB»); dt — дата данных: последний день этого месяца в дневном источнике
    #    руководителей (hr_executive_proteus), нет его — вчера, но не позже конца месяца
    #    21.10 (Адель, бой): последний месяц и дату данных — отдельными запросами, в SQL — литералы. Дата
    #    коррелированным подзапросом от c.lm не даёт GP отсечь партиции дневного источника по параметру:
    #    он сортирует источник целиком и падает «workfile per query size limit exceeded» уже на _cal
    hsrc, hdt = (None, None) if debug else _hub_head_src()
    lm_lit = '2026-09-01' if debug else str(_hub_q(f'select max(report_month)::date as lm from {src}')['lm'].iloc[0])[:10]
    dt_lit = 'null::date'
    if hsrc:
        d = _hub_q(f"""select max(x.{hdt})::date as dt from {_qualified(hsrc)} x
                       where x.{hdt} >= '{lm_lit}'::date and x.{hdt} < ('{lm_lit}'::date + interval '1 month')""")['dt'].iloc[0]
        if d is not None and str(d)[:3] not in ('NaT', 'Non', 'nan'):
            dt_lit = f"'{str(d)[:10]}'::date"
    steps.append(f"""
drop table if exists {p}_cal;
create table {p}_cal as
select '{lm_lit}'::date as lm,
       coalesce({dt_lit}, least(current_date - 1, ('{lm_lit}'::date + interval '1 month' - interval '1 day')::date)) as dt
{dist('lm')}""")

    # 2. пути юнитов последнего месяца — по маленьким таблицам (21.10, Адель, бой: distinct по массивам
    #    ключей и имён 11 уровней на каждой строке месяца уходил в workfile). _uall — группировка по юниту и
    #    его пути (ключи уровней — колонками, не массивом): строк — юниты × их пути, тысячи. _uone — один путь
    #    на юнит, если их несколько — меньший строкой, как раньше: путь берётся целиком, а не минимум
    #    каждого уровня по отдельности (тот мог склеить путь, которого нет, и потерять сам юнит)
    kcol = ', '.join(f's.lvl{i}_rk::text as k{i}' for i in lv)
    ncol = ', '.join(f'min(s.lvl{i}_nm::text) as n{i}' for i in lv)
    k_arr_u = 'ARRAY[' + ', '.join(f'u.k{i}' for i in lv) + ']'
    n_arr_u = 'ARRAY[' + ', '.join(f'u.n{i}' for i in lv) + ']'
    steps.append(f"""
drop table if exists {p}_uall;
create table {p}_uall as
select s.mng_unit_rk::text as unit_rk, s.leaf_lvl, {kcol}, {ncol}
from {src} s
where s.report_month = '{lm_lit}'::date and s.leaf_lvl > 0
group by {', '.join(str(i) for i in range(1, len(lv) + 3))}
{dist('unit_rk')}""")
    steps.append(f"""
drop table if exists {p}_uone;
create table {p}_uone as
select distinct on (unit_rk) *
from (select u.*, array_to_string(({k_arr_u})[1:u.leaf_lvl], '|') as cp from {p}_uall u) x
order by unit_rk, cp
{dist('unit_rk')}""")

    # 2b. путь каждого юнита в последнем месяце (два пути — меньший)
    steps.append(f"""
drop table if exists {p}_upath;
create table {p}_upath as
select unit_rk, cp from {p}_uone
{dist('unit_rk')}""")

    # 3. узлы — все начала путей: и юниты со своими людьми, и уровни над ними без своих строк
    steps.append(f"""
drop table if exists {p}_node;
create table {p}_node as
select rk, min(nm) as nm, min(lv) as lv, min(prk) as prk, min(pth) as pth
from (
    select x.rk, x.nm, x.lv,
           case when x.lv = 1 then '' else x.ra[x.lv - 1] end as prk,
           array_to_string(x.ra[1:x.lv], '|') as pth
    from (
        select unnest(r.ra) as rk, unnest(r.na) as nm, generate_subscripts(r.ra, 1) as lv, r.ra
        from (
            select ({k_arr_u})[1:u.leaf_lvl] as ra, ({n_arr_u})[1:u.leaf_lvl] as na
            from {p}_uone u
        ) r
    ) x
    where x.rk <> '-'
) n
group by rk
{dist('rk')}""")

    _hub_run(steps, 'cal / uall / uone / upath / node', debug)
    steps = []

    # несколько корней — общий корень над ними: «вся компания» — сумма всех строк
    roots = 0 if debug else int(_hub_q(f"select count(*) as n from {p}_node where prk = ''")['n'].iloc[0])
    multi = roots > 1
    pre = f"'{HUB_ALL}|' || " if multi else ''
    if multi:
        steps.append(f"""
update {p}_node set prk = '{HUB_ALL}' where prk = '';
update {p}_node set pth = '{HUB_ALL}|' || pth, lv = lv + 1;
insert into {p}_node (rk, nm, lv, prk, pth) values ('{HUB_ALL}', 'Все юниты', 1, '', '{HUB_ALL}')""")

    # Тяжёлые шаги — частями по месяцам (21.10: на полном объёме «ERROR: workfile per query size limit
    # exceeded» — Greenplum не хватает рабочей памяти на промежуточные результаты одного запроса). Ряды
    # (6), разрезы (8) и переходы (10) считаются помесячно: первая часть создаёт таблицу, остальные —
    # insert; месяц — ключ группировки, поэтому части не пересекаются
    if debug:
        months, lm_d = ['2026-09-01'], dt_.date(2026, 9, 1)
    else:
        months = [str(x)[:10] for x in _hub_q(
            f"select distinct report_month::date as m from {src} where leaf_lvl > 0 order by 1")['m']]
        lm_d = dt_.date.fromisoformat(str(_hub_q(f"select lm from {p}_cal")['lm'].iloc[0])[:10])
    m_ytd = [m for m in months if m[:4] == str(lm_d.year) and m <= str(lm_d)]
    m_grid = [str(dt_.date(lm_d.year - 1 + (i // 12), i % 12 + 1, 1)) for i in range(12 + lm_d.month)]
    mw = lambda m: f"and s.report_month = '{m}'::date"

    def parts(table, body, keys, dkey):
        keys = keys or [None]
        return ([f"drop table if exists {table};\ncreate table {table} as\n{body(keys[0])}\n{dist(dkey)}"]
                + [f"insert into {table}\n{body(k)}" for k in keys[1:]])

    # 4. руководитель юнита на конец последнего месяца (на дату данных) — голосами, как в HRBP HUB:
    #    3 — сам руководитель (management_head_flg = 1) в юните → его ad_login; 2 — люди юнита →
    #    их management_head_ad_login; 1 — руководители подразделений → их management_head_ad_login
    #    (у юнита без своих людей). Старший голос, внутри — самый частый логин, при равенстве —
    #    меньший. Человек — в юните строки конца месяца (численность > 0), источник логинов —
    #    по mdm_employee_rk на последнюю дату месяца — дату данных литералом (как в _cal: подзапрос по
    #    дневному источнику GP не режет партициями)
    if hsrc and has('mdm_employee_rk'):
        hh = f"""(
        select e.mdm_employee_rk as erk, max(coalesce(e.management_head_flg::text, '0'))::int as is_head,
               max(nullif(lower(trim(e.ad_login::text)), '')) as login,
               max(nullif(lower(trim(e.management_head_ad_login::text)), '')) as head_login
        from {_qualified(hsrc)} e
        where e.{hdt} = {dt_lit}
        group by 1)"""
        steps.append(f"""
drop table if exists {p}_head;
create table {p}_head as
select distinct on (unit_rk) unit_rk, head_login
from (
    select v.unit_rk, v.head_login, max(v.w) as w, count(*) as n
    from (
        select s.mng_unit_rk::text as unit_rk,
               case when h.is_head = 1 then h.login else h.head_login end as head_login,
               case when h.is_head = 1 then 3 else 2 end as w
        from {src} s
        join {hh} h on h.erk = s.mdm_employee_rk
        where s.report_month = (select lm from {p}_cal) and s.leaf_lvl > 0 and {snum('hc_total_cnt')} > 0
        union all
        select n.prk, h.head_login, 1
        from {src} s
        join {hh} h on h.erk = s.mdm_employee_rk
        join {p}_node n on n.rk = s.mng_unit_rk::text
        where s.report_month = (select lm from {p}_cal) and s.leaf_lvl > 0 and {snum('hc_total_cnt')} > 0
          and h.is_head = 1 and n.prk <> ''
    ) v
    where v.head_login is not null and v.unit_rk is not null
    group by v.unit_rk, v.head_login
) t
order by unit_rk, w desc, n desc, head_login
{dist('unit_rk')}""")
    else:
        steps.append(f"""
drop table if exists {p}_head;
create table {p}_head as select ''::text as unit_rk, ''::text as head_login where false
{dist('unit_rk')}""")

    # 5. справочник узлов: + число подразделений и логин руководителя
    steps.append(f"""
drop table if exists {p}_unit;
create table {p}_unit as
select n.rk as unit_rk, n.prk as parent_rk, n.lv as unit_lvl, n.nm as unit_nm,
       coalesce(k.kids, 0)::int as kids_cnt, n.pth as path_rk, coalesce(h.head_login, '') as head_login
from {p}_node n
left join (select prk, count(*) as kids from {p}_node where prk <> '' group by prk) k on k.prk = n.rk
left join {p}_head h on h.unit_rk = n.rk
{dist('unit_rk')}""")
    _hub_run(steps, 'head / unit', debug)
    steps = []

    # 6. строки источника → узлы нынешней структуры. История — по пути юнита в последнем
    #    месяце (переехал — прошлое едет с ним); юнита нет — по своему пути.
    #    Перевод входит в узел глубины d, если сменился уровень ≤ d (через границу узла)
    # тип численности (20.10): «Активная» — тип активности строки на конец месяца (по флагу
    # источника, FIXED_DIMS), остальные — «Прочие». Отчёт по умолчанию — только «Активная»
    act_c = ("case when s.active_type_gr_nm = 'Активная' then 'Активная' else 'Прочие' end"
             if has('active_type_gr_nm') else "'Активная'::text")
    expl = f"""
    select x.*, unnest(string_to_array(x.cp, '|')) as node_rk,
           generate_subscripts(string_to_array(x.cp, '|'), 1) - {1 if multi else 0} as d
    from (
        select s.*, {pre}coalesce(u.cp, {path_rk}) as cp,
               {cut('paint_cd', 'paint_c')}, {cut('emp_specialization_it_code', 'it_c')},
               case when s.employment_relation_type = '{staff_value}' then 'Штат' else 'Не штат' end as staff_c,
               {act_c} as act_c
        from {src} s
        left join {p}_upath u on u.unit_rk = s.mng_unit_rk::text
        where s.leaf_lvl > 0 {{where}}
    ) x"""
    steps.extend(parts(f'{p}_sx', lambda m: f"""
select node_rk, report_month::date as report_month, paint_c, it_c, staff_c, act_c,
       sum({num('hc_total_cnt')}) as hc, sum({num('hc_active_cnt')}) as act,
       -- найм по методологии DD: найм в компанию + перевод из учебной группы в боевую + стажёров в
       -- штат; одно событие на человека в строке: тип активности в источнике — на конец месяца,
       -- и стажёр, принятый и переведённый в одном месяце, иначе попал бы и в найм, и в перевод
       sum(greatest({num('hire_amt')}, {num('transfer_candidate_amt')}, {num('transfer_internal_amt')})) as hire,
       -- найм в компанию с любым типом активности — найм «всей численности» (методология: по
       -- юридической численности найм — только событие «Найм в компанию»)
       sum({num('hire_cnt') if has('hire_cnt') else num('hire_amt')}) as hco,
       sum({num('fire_amt')}) as fire, sum({num('regret_fire_amt')}) as reg,
       -- обычные (non-regrettable) увольнения — как в прод-ноутбуке HQ (21.10)
       sum({num('non_regret_fire_amt')}) as nreg,
       sum(case when {num('transfer_in_lvl')} between 1 and d then {num('transfer_in_amt')} else 0 end) as tin,
       sum(case when {num('transfer_out_lvl')} between 1 and d then {num('transfer_out_amt')} else 0 end) as tout,
       sum({num('perf_normal')}) as pnor, sum({num('perf_low')}) as plow,
       sum({num('perf_high')}) as phig, sum({num('perf_gray')}) as pgry,
       sum({num('work_day_amt')}) as wday, sum({num('office_visit_amt')}) as ovis,
       sum({num('grt_approve_cnt')}) as gapr, sum({num('grt_decline_cnt')}) as gdec
from ({expl.replace('{where}', mw(m))}) e
group by 1, 2, 3, 4, 5, 6""", months, 'node_rk'))

    #     методология переводов translations_logic.md: факт перевода — флагом источника, не сравнением значений).
    #     Выбор отчёта — узел и фильтры (покраска, IT-код, штат, тип численности). Человек входит в выбор или
    #     выходит из него, когда меняются его юнит или срез. Смена считается переводом, только если её отметил

    #     читает и TP 2.0: «в» — против прошлого дня, «из» — против следующего). Поэтому переход между днями

    #       i, o, s — перевод: вошёл в узел, вышел, остался со сменой среза (s — только если срез сменился);

    #                 активной численности это найм (методология DD), на всей — перевод (методология переводов:
    #                 кандидатов исключают только «в активной численности»); из выбора — не после увольнения
    #       h       — найм в компанию: узлы и срез дня найма (а не конца месяца: найм и перевод того же месяца

    #       x…      — смены без флага источника, для сверки: xi / xo / xs — часть перехода без флага (по
    #                 значениям), xa — появился без найма, xd — пропал без увольнения. На чистых данных их нет;
    #                 если есть — это и есть «прочее» водопада (методология: прочее — только при сбое данных)
    #     Пути юнитов — нынешние, как у рядов (переименование и переезд юнита — не перевод)

               case when {dleaf} = 0 then '' else ({darr})[{dleaf}] end as u,

               {tflg('to', 'it')} as ii, {tflg('out', 'it')} as oi,

    # 12. AI-инструменты (21.10) — как в прод-ноутбуке HQ (параграф «ai_bi monthly»): WAU и проникновение
    #     посчитаны в источнике по юниту (строка юнита — всё его поддерево), здесь не суммируются, а берутся
    #     у своего узла. Корню отчёта, если в источнике его нет, — сумма WAU верхнего уровня источника и
    #     проникновение по компании. Источник — не люди: фильтры среза на AI не действуют
    try:
        acols = set() if debug else _source_cols(_qualified(ai_source))
    except Exception:
        acols = set()
    if debug or {'month', 'mngt_unit_rk', 'avg_wau', 'avg_penetration_unit_pct'} <= acols:
        aco = 'a.avg_penetration_company_pct' if (debug or 'avg_penetration_company_pct' in acols) else 'null::float8'
        alv = 'a.lvl' if (debug or 'lvl' in acols) else '0'
        steps.append(f"""
drop table if exists {p}_ai;
create table {p}_ai as
with a as (
    select date_trunc('month', a.month::date)::date as report_month, a.mngt_unit_rk::text as node_rk,
           max(a.avg_wau)::float8 as ai_wau, max(a.avg_penetration_unit_pct)::float8 as ai_pen,
           max({aco})::float8 as ai_pen_co, min({alv}) as lv
    from {_qualified(ai_source)} a
    where a.month::date between '{m_grid[0]}'::date and ('{m_grid[-1]}'::date + interval '1 month' - interval '1 day')
    group by 1, 2
)
select report_month, node_rk, ai_wau, ai_pen, ai_pen_co from a
union all
select a.report_month, r.unit_rk, sum(a.ai_wau), max(a.ai_pen_co), max(a.ai_pen_co)
from a
cross join (select unit_rk from {p}_unit where parent_rk = '') r
where a.lv = (select min(lv) from a a2 where a2.report_month = a.report_month)
  and not exists (select 1 from a a3 where a3.node_rk = r.unit_rk)
group by 1, 2
{dist('node_rk')}""")
    else:
        print(f'[WARN] {ai_source}: нет таблицы или колонок — {p}_ai пустая, AI в отчёте «в разработке»')
        steps.append(f"""
drop table if exists {p}_ai;
create table {p}_ai (report_month date, node_rk text, ai_wau float8, ai_pen float8, ai_pen_co float8)
{dist('node_rk')}""")

    # 9. календарь отчёта, корень и юнит по умолчанию (у корня один ребёнок — он)
    steps.append(f"""
drop table if exists {p}_meta;
create table {p}_meta as
select c.lm as last_month,
       c.dt as data_dt,
       (date_trunc('year', c.lm) - interval '1 year')::date as grid_start,
       (12 + date_part('month', c.lm))::int as n_months,
       12 as ytd_idx,
       r.unit_rk as root_rk,
       case when r.kids_cnt = 1 then (select unit_rk from {p}_unit where parent_rk = r.unit_rk) else r.unit_rk end as def_rk,
       now() as built_at,
       'hub-2' as schema_ver
from {p}_cal c
cross join (select unit_rk, kids_cnt from {p}_unit where parent_rk = '' order by unit_rk limit 1) r
{dist('last_month')}""")

    steps.append(f"drop table if exists {p}_sx; drop table if exists {p}_node; drop table if exists {p}_head; "
                 f"drop table if exists {p}_uall; drop table if exists {p}_uone")
    _hub_run(steps, 'sx / series / mix / trf / vacancy / ai / meta', debug)
    if debug:
        return
    for t in ('meta', 'unit', 'series', 'mix', 'trf', 'vacancy', 'ai'):
        n = _hub_q(f'select count(*) as n from {p}_{t}')['n'].iloc[0]
        print(f'[OK] {p}_{t}: {n} строк')
    if multi:
        print(f'[INFO] корней {roots} — общий корень «{HUB_ALL}»')
```
