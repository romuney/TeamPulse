# Огонёчек «Пульс» — гайд по встройке маскота в TeamPulse

Стикер-пак: 10 персонажей × 5 размеров (1024/512/256/128/64), PNG с настоящей прозрачностью.
Единый стиль: глянцевый 3D-каплевидный огонёк без рук и ног (руки появляются только в «рабочих» позах), вязаная повязка с линией пульса.

## Роли и цветовая кодировка

| Стикер | Роль | Кодировка |
|---|---|---|
| `pulse_base` | Лого, нейтральные места, аватар ассистента | Оранжевый + синяя повязка (базовый бренд) |
| `pulse_ai` | Все AI-подсказки и предрасчёты | Фиолетовый, повязка с надписью **AI** |
| `pulse_hello` | Онбординг, приветствие, первый вход | Оранжевый, машет |
| `pulse_point` | Подсказки «смотри сюда», coach marks | Оранжевый, указывает |
| `pulse_zoom` | Drill-down, «Детальный дашборд», разбор | Оранжевый, с лупой |
| `pulse_ok` | Метрика в норме / лучше базы | Зелёная повязка, радость |
| `pulse_warn` | Метрика на грани (±5%) | Янтарная повязка, настороженность |
| `pulse_alert` | Хуже базы / «Требует действий» | Красная повязка и тело, тревога |
| `pulse_setup` | «Настрой свой дашборд», фильтры | С гаечным ключом и шестерёнкой |
| `pulse_nodata` | Пустые состояния, нет данных | Погасший серо-голубой, спит |

Кодировка эмоций сознательно совпадает со светофорной гаммой отчёта (лучше базы / на уровне / хуже базы) и не пересекается с предметной палитрой потоков.

## Карта размещения (по текущей вёрстке)

1. **Шапка, лого** — `.logo .mark` → `pulse_base` 28–30 px. Сейчас там пустой синий квадрат; маскот становится знаком продукта.
2. **AI-строки** — `.ai-ico` (в `aiBlock`: «Как читать эту сводку» на OnePager, «Главное в блоке» на детальных вкладках) → `pulse_ai` 24–28 px вместо синего квадратика «AI». Пользователь мгновенно считывает: это говорит AI.
3. **Инсайты с серьёзностью** — `.ai.insight.sev-high|sev-mid|sev-good` → `pulse_alert` / `pulse_warn` / `pulse_ok` 24–28 px. Эмоция дублирует цвет рамки и делает статус считываемым до чтения текста.
4. **Модалка «Как читать отчёт»** (`#helpOvl .modal-h`) → `pulse_hello` 80–96 px, выступает за верх модалки (`position:absolute; top:-30px; right:20px`). Внутри секций справки — `pulse_point` 32–36 px у ключевых подсказок (например, «KPI важнее средней»).
5. **Модалка «Настрой свой дашборд»** (`#setupOvl .modal-h`) → `pulse_setup` 72–80 px, тот же приём с выступом.
6. **Плавающий ассистент (FAB)** — правый нижний угол, `pulse_hello`/`pulse_base` 64–74 px + пузырь реплики. Точка входа в объяснения метрик и будущие AI-диалоги; «пользователь всегда под присмотром огонёчка».
7. **Пустые состояния** — панели с нулём данных (`.panel-b`) → `pulse_nodata` 96 px + «Здесь пока нет данных». Тон мягкий: огонёчек уснул, а не «ошибка».
8. **Будущее: KPI-карточки** — когда появится статус ок/не-ок у метрик, `pulse_ok`/`pulse_warn`/`pulse_alert` 20–24 px в углу `.kpi` или рядом с пилюлей сравнения. В таблицах OnePager маскота не ставим — там слишком плотно, достаточно цвета пилюль.

## Правила использования

- Минимальный размер: 20 px (мельче — повязка и лицо не читаются). Надпись AI читается от ~24 px.
- До 64 px использовать файлы из `128/`, 64–128 px — из `256/`, крупнее — `512/`.
- Не более одного «эмоционального» маскота на строку/карточку; `pulse_ai` не смешивать с эмоциями в одном блоке.
- Тень: `filter: drop-shadow(0 6px 12px rgba(15,23,42,.2))` только для «плавающих» маскотов (FAB, модалки); встроенные в строки — без тени.
- Файлы обрезаны по контенту с полем 4%, центрированы — можно ставить в квадратный контейнер без доводки.

## Рендеры
