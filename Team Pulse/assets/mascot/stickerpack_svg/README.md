# Стикер-пак «Пульс» в SVG

Те же 10 персонажей, что и в `../stickerpack/`, но в векторе — по одному файлу
на персонажа:

```
pulse_base.svg   pulse_ai.svg     pulse_hello.svg  pulse_point.svg  pulse_zoom.svg
pulse_ok.svg     pulse_warn.svg   pulse_alert.svg  pulse_setup.svg  pulse_nodata.svg
```

Роли и цветовая кодировка не меняются — они описаны в `../MASCOT_GUIDE.md`.

## Почему нет подпапок 64/128/256/512/1024

Размерные варианты нужны растру, вектор масштабируется сам. Один `pulse_base.svg`
закрывает все пять размеров из PNG-пака и любой промежуточный:

```html
<img src="assets/mascot/stickerpack_svg/pulse_base.svg" style="width:28px;height:28px">
```

Внутри у файлов `viewBox="0 0 512 512"` при `width`/`height` = 1024, то есть без
CSS-размера картинка встанет как мастер 1024×1024, а с любым заданным размером
отрисуется чётко. Прозрачность и обрезка по контенту с полем 4% — как у PNG,
доводка под квадратный контейнер не нужна.

## Что это за вектор

Это трассировка 3D-рендеров, а не нарисованный с нуля вектор: глянцевые
градиенты разложены на ~700–1100 наложенных плоских заливок. На размерах
встройки (20–96 px по гайду) от PNG не отличается; при увеличении до
нескольких тысяч px градиенты видны ступенями, а края остаются резкими.

Отсюда и вес: 440–610 KB на файл против 787 KB у PNG 1024, но против 12–20 KB
у PNG 128. Для мест из гайда, где маскот стоит 20–96 px, PNG из `../stickerpack/`
по-прежнему легче — SVG выигрывает там, где размер заранее не известен
(ретина-экраны, зум, печать, экспорт в макеты).

## Перегенерация

Файлы генерируются из мастеров `../stickerpack/1024/*.png`, поэтому править их
руками не нужно — правится PNG-мастер и запускается конвертер:

```sh
pip install pillow vtracer
python3 "Team Pulse/assets/mascot/tools/png_to_svg.py"
```

Параметры трассировки и их обоснование — в шапке `../tools/png_to_svg.py`.

## Чего здесь нет

`../renders/*.png` и `../stickerpack_preview.png` не векторизованы намеренно:
первое — скриншоты реального отчёта, второе — контактный лист с подписями.
Трассировка скриншота даёт файл в разы тяжелее исходника и хуже читаемый текст;
для этих двух ролей растр — правильный формат.
